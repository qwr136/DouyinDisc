# DouyinDisc · TrollFools

## 4.00：移除文件选择器

照片选择使用 UIKit 全屏系统照片库界面和系统取消按钮；不再提供文件选择器。下滑行为需在目标设备实测，CI 测试不等同真机手势验收。

每项素材行仅保留照片选择/更换按钮和删除按钮。设置页重新出现时，如果当前 picker 已不在展示/退场状态且取消代理未触发，则按 picker 对象身份回收此会话并撤销空选择票据；取得有效照片导入票据会保留。无固定延时清理。

模拟器回归覆盖：原生照片库全屏展示、系统取消回调完成收尾；检查取消后的亮度、照片/开关触控、票据撤销以及图片和配置保持不变。此仍不是用户设备真机验收。

在面板改为白色圆角卡片，每项显示预览、照片选择/更换与删除；透明度和大小用减号/百分比/加号控制，点击百分比可输入整数，范围分别为0%–100%与50%–150%。3.70的配置和素材路径沿用。

本次保留照片页只能通过系统取消按钮退出的行为；文件选择器已删除。是否符合目标需真机验收。

修复导航图标定位与原文字残留，提供每项 50%–150% 独立大小调节；入口插入根设置“通用”分组，紧跟运行时识别到的“抖音图层”项，黑字 `DouyinDisc`。找不到原生锚点时跳过，不猜固定位置。素材按钮仅在对应开关成功开启后可用；关闭开关会撤销在途导入，保留原图。选中状态显示照片图标、“更换图标”和独立缩略图，删除按钮贴近素材按钮。

每项独立控制：首页顶部 9 个分类、底部 4 个导航文字。图标以顶部 tab 中心 / 底部标签矩形为定位基准，不更改中间“+”、顺序、原点击或角标。

顶部：推荐、关注、同城、精选、商城、团购、直播、热点、经验。底部：首页、朋友、消息、我。

目标 App `com.ss.iphone.ugc.Aweme`，按短版本数字组件放行 `39.9.0` 至 `41.2.0`（含两端），不限制 build。接受三段十进制或 `M.mp` 紧凑写法（如 `39.90`、`40.12`、`41.20` 分别为 `39.9.0`、`40.1.2`、`41.2.0`）；拒绝畸形和区间外版本。放行不等于已验证兼容；最低 iOS 15.0。作者 Xiaofei，插件标识 `com.minis.douyindisc`。TrollFools 单文件 arm64 `.dylib`。

## 图标配置

设置卡片以“− / 数值 / +”调节透明度（0%–100%）与图标大小（默认100%，范围50%–150%）；点击百分比可输入整数。每项都有独立替换开关。只能从系统照片选择图标；文件选择入口已移除。图片缩小到最长边 512 px 后存入抖音沙盒 `Documents/DouyinDisc/Navigation/`，配置文件为 `settings.plist`。关闭开关或清除自定义图片后恢复原文字。图片使用原比例，不拉伸；图片本身的透明度和设置百分比相乘。

## 原圆盘功能

保留圆盘替换、StyleOne 与 SingleSong 半盘修复、“拍同款/玩同款”精确隐藏、原生点击/分享，以及中心环 90%、外圈 50% 的同步旋转。1.50 移除的“圆盘取证”按钮、日志采集和导出不再包含。

## 边界与验收

静态定位依据是用户提供的抖音 build 399017 同版样本；短版本门控放行 39.9.0–41.2.0，但区间内新版本尚无逐版取证。真实设备上的主设置入口命中、导航视图树匹配、13 项显示、原生角标/点击以及照片导入仍需真机验收。不能把模拟器回归或 Actions 成功当作设备已验证。横屏和 iPad 不承诺适配。

安装时先在 TrollFools 移除旧版，再注入本版并完全退出、重开抖音。进入“我→菜单→设置”，在“通用”分组找到“抖音图层”下方的 DouyinDisc，先开启单项再从照片选择图标测试。故障反馈提供抖音版本、被替换项目的截图；闪退附对应 `.ips`。
