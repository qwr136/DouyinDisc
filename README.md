## 3.90：卡片式面板与照片页仅按钮关闭

照片选择器设为 isModalInPresentation，禁止交互式下滑关闭；只能点系统取消按钮。关闭代理仍用于收尾；转场完成回调校验取消/完成，并在取消时重绑代理。另在照片选择器展示期间运行主线程轻量窗口状态监测：仅当同一 picker 曾进入窗口、随后连续脱离且仍属于当前展示会话时才回收取消状态；有效导入票据保留。文件选择器及其他导航行为不改。设置根入口的首屏插入和原生右箭头沿用3.60实现。

UIKit回归使用UIKit原生照片选择器系统取消路径，验证关闭后照片/文件/开关入口恢复。下滑关闭已由全屏照片界面阻止卡片式下滑；真机仍需确认系统取消可用及其余页面表现，CI不等于真机验收。

素材行采用独立的照片按钮和文件夹按钮，分别直接打开系统照片选择器与文件选择器，不再叠加来源菜单。设置页重新出现时，如果当前picker已不在展示/退场状态且取消代理未触发，则按picker对象身份回收此会话并撤销空选择票据；取得有效provider的导入票据会保留。无固定延时清理。

模拟器回归覆盖：照片页被标记为不可交互下滑关闭、系统取消回调完成收尾、直接打开文件选择器并取消；检查取消后的亮度、照片/文件/开关命中、票据撤销以及图片和配置保持不变。此仍不是用户设备真机验收。

在面板改为白色圆角卡片，每项显示预览、照片/文件、删除；透明度和大小用减号/百分比/加号控制，点击百分比可输入整数，范围分别为0%–100%与50%–150%。3.70的配置和素材路径沿用。

本次专门按用户要求禁止照片页下滑退出；系统取消按钮与文件选择不变。是否符合目标需真机验收。

## 图标配置

设置卡片以“− / 数值 / +”调节透明度（0%–100%）与图标大小（默认100%，范围50%–150%）；点击百分比可输入整数。每项都有独立替换开关与图片来源。可从系统照片或文件选择图片；图片缩小到最长边 512 px 后存入抖音沙盒 `Documents/DouyinDisc/Navigation/`，配置文件为 `settings.plist`。关闭开关或清除自定义图片后恢复原文字。图片使用原比例，不拉伸；图片本身的透明度和设置百分比相乘。

## 原圆盘功能

保留圆盘替换、StyleOne 与 SingleSong 半盘修复、“拍同款/玩同款”精确隐藏、原生点击/分享，以及中心环 90%、外圈 50% 的同步旋转。1.50 移除的“圆盘取证”按钮、日志采集和导出不再包含。

## 边界与验收

静态定位依据是用户提供的抖音 build 399017 同版样本；真实设备上的主设置入口命中、导航视图树匹配、13 项显示、原生角标/点击以及照片/文件导入仍需真机验收。不能把模拟器回归或 Actions 成功当作设备已验证。其它抖音 build、横屏和 iPad 不承诺适配。

安装时先在 TrollFools 移除旧版，再注入本版并完全退出、重开抖音。进入“我→菜单→设置”，在“通用”分组找到“抖音图层”下方的 DouyinDisc，先开启单项再导入图片测试。故障反馈提供抖音版本、被替换项目的截图；闪退附对应 `.ips`。
